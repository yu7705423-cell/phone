# 网易云转发：部署到 Cloudflare（给运营方看）

用户打开应用就能搜歌、扫码登录网易云，什么都不用填 —— 前提是你照下面做一次。
全程在网页上点，不需要服务器，不需要懂代码，大约 15 分钟。免费。

> Cloudflare 的后台隔一阵会改版，按钮的名字和位置可能和这里写的略有出入。
> 找不到某个按钮时，认准它的意思：「新建 Worker」「编辑代码」「部署」。

---

## 它是什么，为什么要它

浏览器不许网页直接访问网易云（网易云不允许别的网站跨域调用它），
也不许网页自己设置登录用的那些请求头。这两件事只能由一个中间的服务器替它做。

`worker/netease.js` 就是这个中间人，只有几十行。它**只会**把请求转给网易云的那三个域名，
别的地址一律拒绝；不记录、不保存任何东西。加密、拼参数都在应用里做。

Cloudflare Workers 是 Cloudflare 提供的「放一小段代码在它那儿跑」的服务，
免费额度每天 10 万次请求。500 个用户正常听歌、搜歌，一般用不完。

## 第一步：注册 Cloudflare

1. 打开 <https://dash.cloudflare.com/sign-up>
2. 填邮箱和密码，点「Sign up」（注册）
3. 去邮箱里点 Cloudflare 发来的验证链接
4. 登录后如果问你要不要添加网站（Add a site / Onboard a domain），**跳过**，不需要域名

## 第二步：新建一个 Worker

1. 左侧菜单找到 **Workers & Pages**（有时在「Compute (Workers)」下面）
2. 点 **Create**（创建）
3. 选 **Worker**，再选 **Start with Hello World!**（从 Hello World 开始）
4. 给它起个名字，例如 `phone-netease`（只能用小写字母、数字和横线）
5. 点 **Deploy**（部署）。这时部署的是一个示例，下一步换成我们的

## 第三步：换成我们的代码

1. 部署成功的页面上点 **Edit code**（编辑代码）。会打开一个代码编辑器
2. 左边文件列表里点开 `worker.js`（有的版本叫 `index.js`）
3. 在右边代码区域里全选（电脑上按 `Ctrl + A`，Mac 按 `Command + A`），删掉
4. 打开本仓库的 [`worker/netease.js`](./netease.js)，**整个文件**全选、复制，粘进去
5. 右上角点 **Deploy**（部署），确认

## 第四步：记下地址，确认它活着

1. 部署成功后，页面上会显示一个地址，形如

   ```
   https://phone-netease.你的名字.workers.dev
   ```

   复制下来
2. 把这个地址直接在浏览器里打开，看到下面这样一行就对了：

   ```
   {"ok":true,"name":"mini-phone-netease","version":1}
   ```

## 第五步（建议做）：只允许你们的网站使用

不做这一步也能用，但别的网站也能拿你的 Worker 去调，额度会被别人花掉。

1. 回到代码编辑器（Workers & Pages → 点你的 Worker → Edit code）
2. 找到这一行：

   ```js
   const ALLOW_ORIGINS = [];
   ```

3. 改成你们网站的地址。**只写到域名为止，结尾不加斜杠**。例如应用的网址是
   `https://phone.example.com/index.html`，就写：

   ```js
   const ALLOW_ORIGINS = ['https://phone.example.com'];
   ```

   有几个网址就写几个，用英文逗号隔开：`['https://a.com', 'https://b.com']`
4. 点 **Deploy**

## 第六步：填进应用

1. 打开仓库里的 `src/site.js`，找到：

   ```js
   neteaseWorker: '',
   ```

   把第四步的地址填进两个单引号之间（**结尾不加斜杠**）：

   ```js
   neteaseWorker: 'https://phone-netease.你的名字.workers.dev',
   ```

   上面那个 `neteaseApi` 保持空着。两个都填的话，应用用的是 `neteaseApi`。
2. 改构建号。这两处要改成同一个新值（在原来的基础上把最后的数字加一即可）：
   - `src/version.js` 里的 `BUILD = '...'`
   - `index.html` 里的 `<meta name="build" content="...">`

   不改的话，用户手机上可能还在跑缓存里的旧代码，看不到这次的改动。
3. 照平常的方式把网站更新上去

## 第七步：测试

1. 用手机打开应用，进「设置 - 音乐服务」
2. 应该能看到「本站已提供音乐转发服务，留空即使用它」
3. 点「**测试这个地址**」，等它逐项跑完
4. **把整页截图发给开发者**。哪一项不通，照截图改哪一项

## 开通登录账号（要登录才能用 Eira）

做完这一节，用户打开 Eira 会先看到登录页；账号由你在应用里的「管理账号」页发放，不开放注册。
一个账号最多同时在 2 台设备上登录，第 3 台登录时最早那台自动退出。

不做这一节，一切照旧，不需要登录。

### 1. 更新 Worker 代码

账号功能在新版的 `worker/netease.js` 里。照「第三步」再做一遍：Edit code，全选删掉，
把仓库里最新的 `worker/netease.js` 整个粘进去，Deploy。
在浏览器里打开 Worker 地址，看到 `"version":2` 就是新版。

### 2. 建一个存账号的地方（KV）

1. 左侧菜单 **Storage & Databases**（存储和数据库）→ **KV**（有的版本在 Workers & Pages 下面）
2. 点 **Create**（创建），名字填 `eira-accounts`，确认

### 3. 把它接到 Worker 上

1. 回到 Workers & Pages，点你的 Worker → **Bindings**（绑定），或 **Settings** → **Bindings**
2. 点 **Add binding**（添加绑定）→ 选 **KV namespace**（KV 命名空间）
3. **Variable name**（变量名）填 `ACCOUNTS`（必须一字不差，全大写）
4. **KV namespace** 选刚才建的 `eira-accounts`
5. 保存（Add binding / Save）

### 4. 设管理员密码

1. 还是这个 Worker → **Settings**（设置）→ **Variables and Secrets**（变量和机密）
2. 点 **Add**（添加）
3. **Type**（类型）选 **Secret**（机密），不要选 Text
4. **Variable name** 填 `ADMIN_PASSWORD`（一字不差，全大写）
5. **Value** 填你的管理员密码：**至少 12 位**，越长越好，不要和别的地方用同一个。少于 12 位账号功能不会开启
6. 保存（Deploy）

**这个密码只有你知道。** 有了它就能发放、停用任何账号。
改这个密码会让所有用户都退出登录一次（他们用原来的账号密码重新登录即可）。

### 5. 发第一个账号

1. 在浏览器里打开 Worker 地址，看到 `"accounts":true` 就说明开通了
2. 打开 Eira，这时已经要求登录。**账号填 `admin`，密码填管理员密码**，就能进去。
   `admin` 这个名字留给你自己，不会发给别人，也不占「最多 2 台设备」的名额
3. 进「设置 - 登录账号 - 管理账号」，再输一次管理员密码 →「新建账号」或「批量新建」→
   复制账号密码发给用户。**密码只在生成时显示一次**，关闭前请复制保存
4. 用户忘了密码：在管理页点他的账号 →「重置密码」，把新密码发给他

### 用量

免费额度够 500 人用：每次打开 Eira 读一次存储；登录、改密码、停用各写一次（每天 1000 次写入的额度）。
批量新建 500 个账号要写 500 次，建议分两天做，或者一天建完后当天少做别的改动。

## 可能遇到的情况

**「连得上」不通**

- 先在浏览器里直接打开 Worker 地址（第四步第 2 点）。打不开说明部署没成功，回第三步重来
- 打得开，但应用里不通：多半是第五步的 `ALLOW_ORIGINS` 写错了。
  检查是不是多了斜杠、少了 `https://`、域名拼错。实在不行先改回 `[]` 试一下
- **在中国大陆，`*.workers.dev` 这个域名有时会被运营商拦掉**，表现为有的用户能用、有的不能。
  解决办法是给 Worker 绑一个自己的域名：Worker 页面 → **Settings**（设置）→
  **Domains & Routes**（域名和路由）→ **Add** → **Custom domain**，
  填一个你在 Cloudflare 上管理的域名下的子域名（例如 `ne.example.com`），
  然后把 `src/site.js` 里的地址换成它。这一步需要你有一个域名并且已经加到 Cloudflare 上

**搜歌、取 key 那几项显示「网易云要求先完成验证」（code -462）**

这是网易云按请求来源拦的。应用已经给每台设备固定了一个随机的中国大陆 IP 随请求发过去，
多数时候能过。个别用户不通时，可以让他在「设置 - 音乐服务 - 来源地址 realIP」
换填另一个中国大陆 IP 再测。整体都不通的话把截图发给开发者。

**有一天突然全都不通了，第二天早上 8 点后又好了**

免费额度（每天 10 万次）用完了。Cloudflare 按世界标准时间零点重置，也就是北京时间早上 8 点。
用户多了经常这样的话，可以在 Cloudflare 后台升级到付费的 Workers Paid（每月 5 美元起），
代码不用改。

## 安全上要知道的

- 用户登录网易云之后，他的登录凭据（cookie）每次请求都会经过这个 Worker 转给网易云。
  这段代码不记录、不保存它；凭据放在请求内容里，不在网址里。
  为稳妥起见，可以在 Worker 页面 → **Settings**（设置）→ **Observability**（可观测性）
  里把 **Workers Logs** 关掉。新建的 Worker 有时默认开着，它不影响使用，关掉更干净。
  以后排查问题需要看日志时，再临时打开
- 这个 Worker 只会转发到网易云的三个域名，改不成别的用途
- 以后网易云改了接口，要改的是应用里的代码（`src/system/ne/`），这个 Worker 一般不用动
