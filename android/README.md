# 安卓外壳

把 Eira 装成一个安卓 app。和 `ios/` 一样：一个铺满屏幕的 WebView，从网络地址载入网页，
不含任何网页资源。**改了网页代码不需要重新打包**，网页自己会检查版本并更新。

## 它做了什么

| | 说明 |
|---|---|
| 启动页 | 先显示图标与转圈，网页画出来才揭开。没网、系统还在问「是否允许联网」时停在这里等，网络一通自动载入；网络是通的却 20 秒连不上才显示「无法载入」，页面上不出现网址 |
| 替网页发请求 | 与 iOS 外壳同一个接口（`window.webkit.messageHandlers.net`），绕开跨域，语音、生图接口在 app 里能直接连上 |
| 导出备份 | 网页导出的文件写进系统的「下载」（安卓 9 及以下写进应用自己的目录） |
| 选图、选文件 | 支持多选 |
| 麦克风、定位 | 网页用到时才弹系统询问 |
| 返回键 | 交给网页逐级返回；已经在桌面或锁屏时把应用切到后台 |
| 站外链接 | 充值页、网易云等在系统浏览器里打开 |
| 通话悬浮窗 | 通话中点「桌面悬浮窗」开启（第一次会带去系统设置打开「显示在其他应用上层」）。之后离开 Eira，通话以小窗浮在桌面与别的应用上，显示名字、时长与最新一句；点一下回到 Eira，按住可拖。回到 Eira 自动收起 |

还没有的：系统通知、后台保活、健康数据、系统闹钟（iOS 外壳有）。网页里这几项会显示为不可用。

## 从旧版换过来

旧版 apk 打开的是 GitHub Pages 的旧网址（`yu7705423-cell.github.io/phone/`），新版打开 `https://eiraphone.cn/`。
数据按网址分开存，新版打开是空的：**先在旧版里「设置 - 存储与备份」导出完整备份**，装新版后在同一页恢复。
旧版是临时签名的，装新版前系统会要求先卸载旧版 —— 所以一定先导出。

## 打包

仓库的 Actions 里有「打包 apk」。点 **Run workflow** 手动运行，几分钟后在运行记录底部的 Artifacts 里下载
`Eira-apk`，解压得到 `.apk`，发到手机上安装。推一个 `android-v1.0.0` 这样的标签会同时建一个 Release。

## 签名（正式发给用户之前必须做）

安卓只允许**同一个签名**的新版覆盖安装旧版。签名不一样，系统会要求先卸载旧版 ——
**卸载会清掉应用里的全部聊天记录与角色卡**。所以签名钥匙要固定下来，一直用同一把。

开发者给你的那个 `ANDROID_SIGNING.txt` 就是这把钥匙。只做一次：

1. 打开 GitHub 上的仓库 → **Settings**（设置）→ 左侧 **Secrets and variables** → **Actions**
2. 点 **New repository secret**（新建仓库机密）
3. **Name** 填 `ANDROID_SIGNING`（一字不差，全大写）
4. **Secret** 里粘贴 `ANDROID_SIGNING.txt` 的全部内容（一长串字母数字，不要多也不要少）
5. 点 **Add secret**

之后每次打包都用这把钥匙。没设的时候也能打包，但文件名会带「临时签名」，那样的包只适合自己试，
不要发给用户。

**`ANDROID_SIGNING.txt` 请另外存一份在自己手上**（网盘、U 盘都行）。GitHub 上的机密只能写不能读，
万一仓库没了、钥匙也没了，以后的新版就再也覆盖不了用户手机上的旧版。

## 在自己的电脑上打

需要 JDK 17 与安卓 SDK（装 Android Studio 最省事）。

```
cd android
gradle assembleRelease -PsiteUrl=https://你的地址/
```

可用的参数：`siteUrl`、`appVersion`、`appBuild`、`appId`。把签名钥匙解码成 `android/release.p12`
就用正式签名，没有就用调试签名。
